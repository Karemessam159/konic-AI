# Konic AI — النسخة v0.3.3 (دليل المبتدئين)

## تشغيله على جهازك (ويندوز)
1. **اقفل أي نافذة سوداء (Terminal) قديمة** كانت شغّالة للسيرفر القديم.
2. فك الضغط عن الملف في مجلد جديد.
3. دبل كليك على **start.bat**. أول مرة هيسطّب المكتبات (محتاج إنترنت وNode.js).
4. هيفتح المتصفح على http://localhost:5173
5. أول مرة هتظهر لك شاشة **⚙️ الإعدادات**: الصق مفتاح Groq واضغط «حفظ المفتاح». خلاص.
6. سيب النافذة السودا شغّالة طول ما بتستخدم الموقع. لقفل الموقع: Ctrl+C أو اقفلها.

فوق في الموقع: 🟢 = شغّال تمام، 🟡 = محتاج مفتاح، 🔴 = الخادم مش شغّال (شغّل start.bat).

## تغيير المفتاح بعدين
⚙️ الإعدادات ← الصق المفتاح الجديد ← حفظ. بنتأكد إنه شغّال، وبعدين **بيبدّل القديم أوتوماتيك** وكل الرسايل الجاية تمشي بالجديد. مفيش تعديل ملفات ولا إعادة تشغيل.
(المفتاح بيتحفظ في `server/.env` على جهازك.)

## رفعه على GitHub
- **الأسهل والأأمن: برنامج GitHub Desktop** (File ← Add local repository ← Publish). بيحترم `.gitignore` فمش هيرفع المفتاح ولا `node_modules`.
- لو هترفع من موقع GitHub بالسحب والإفلات: ارفع من **مجلد جديد فك ضغطه من الـ zip ومشغّلتوش**. لأن بعد التشغيل بيظهر فيه `server/.env` (فيه مفتاحك) و`node_modules`، والرفع من الموقع **مش بيتجاهلهم**.
- بعد الرفع تقدر تشغّله مباشرة من GitHub: زر **Code ← Codespaces ← Create codespace**. بيسطّب ويشغّل لوحده.

## لو في مشكلة
| الظاهر | الحل |
|---|---|
| 🔴 الخادم غير متصل | شغّل start.bat |
| "المفتاح مش مقبول" | انسخه كامل من console.groq.com/keys |
| "وصلت للحد المسموح (429)" | استنى دقيقة |
| بورت 3001 أو 5173 مشغول | في سيرفر قديم لسه شغّال — اقفل نوافذه |
| الصور مش شغّالة | غيّر `GROQ_VISION_MODEL` في `server/.env` لنموذج يدعم الصور |
فحص شامل: PowerShell في المجلد ثم `powershell -ExecutionPolicy Bypass -File .\KonicAI_Doctor.ps1`

## الجديد في v0.3.3
- شاشة إعدادات لتغيير مفتاح Groq بدون تعديل ملفات.
- أمر واحد يشغّل الخادم والموقع (`npm run dev:all`)، وإمكانية تقديم الموقع من الخادم بورت واحد (`npm start`).
- ملفات GitHub: `README.md`، فحص تلقائي CI، إعداد Codespaces، `.gitattributes`.
- حماية: الخادم بيرفض أي طلب مش JSON، وتغيير المفتاح مقفول لو الخادم على استضافة.

## قبل ما تنشره للناس
- الموقع حاليًا من غير تسجيل دخول: أي زائر بيستهلك رصيد مفتاحك.
- كنت سألت عن تسجيل الدخول بحساب جوجل: ممكن يتضاف، بس محتاج Client ID من Google Cloud، وهو للهوية فقط (مش بيدي استخدام Gemini).
